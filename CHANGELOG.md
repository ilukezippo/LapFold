# Changelog

## 1.0.0

First release.

- Windows-style keyboard on the bottom half: Esc, F1–F12, Tab, Caps, Shift, Ctrl, Win, Alt, arrows, key repeat
- Sticky modifiers: tap once for the next key, twice to lock
- Trackpad with an on-screen pointer: tap to click, right-click, two-finger scroll, drag with the left button
- Mouse-wheel scroll strip, plus Back and Home buttons
- Hide/show arrow with a slide animation; the navigation bar stays reachable
- Auto split screen from the notification or Quick Settings tile
- Gboard stays your default keyboard
- Dark and light themes for the keyboard and the app
- Update check on startup and in Settings
- Remote desktop mode: the trackpad moves Splashtop's own mouse pointer

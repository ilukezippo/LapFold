# LapFold Implementation Plan

> Executed natively in-session (user is on mobile and approved the design; asked to build).

**Goal:** Android app turning the Z Fold bottom half into a Windows keyboard + trackpad usable in any app.
**Architecture:** One AccessibilityService owns two overlays (panel, pointer). Typing via AccessibilityService.InputMethod (API 33+); clicks/scroll/drag via dispatchGesture with continued strokes. MainActivity doubles as split-screen pane placeholder + settings.
**Tech Stack:** Kotlin, AGP 8.7, minSdk 33, targetSdk 35, no third-party deps.
**Spec:** docs/superpowers/specs/2026-11-26-lapfold-design.md

## Global Constraints
- Gboard must never be switched; only hidden (SoftKeyboardController SHOW_MODE_HIDDEN) while on, restored when off.
- No computer/ADB setup.
- Toggle: notification action, QS tile, opening app. Any hinge angle.

## Review Focus
- Rotation / fold-unfold while on: panel + pointer must re-layout to new bounds.
- Service disabled while panel on: Gboard show mode must be restored (onUnbind/onDestroy).
- No focused text field: key presses must not crash (null input connection).
- Modifier keys: one-shot vs locked state; Shift+letter label and meta correct.
- Pointer must stay clamped inside the area above the panel.
